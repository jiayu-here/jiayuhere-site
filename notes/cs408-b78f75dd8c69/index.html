题型

  1. HTTP 连接
  2. DHCP 应用
  3. DNS 与 HTTP 综合

分层总线索

  • 数据单位：比特 → 帧 → 数据报/分组 → 报文段 → 应用报文。
  • 标识对象：MAC 地址标识局域网接口，IP 地址用于跨网寻址，端口号标识主机内进程。
  • 时延计算先拆成发送、传播、处理和排队，再判断流水线、并行、窗口和握手是否改变关键路径。
  • 可靠传输需统一序号、确认号、窗口和超时重传的语义，不能只背协议名称。

与数据结构衔接

  • 最短路径算法是理解链路状态路由计算的算法基础。
