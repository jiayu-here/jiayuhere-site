描述：网络学习先分清“网络和互联网是什么”“交换时是否独占链路”“时延由什么组成”。计算机网络的价值在于通信、共享和协作；Internet 的普适性则来自 TCP/IP 协议族和分组交换。

1.1 计算机网络与互联网

计算机网络（网络）由若干结点和连接结点的链路组成。结点可以是主机、集线器、交换机、路由器等；链路可以是双绞线、光纤、无线链路等。

多个网络再借助路由器互连，构成覆盖范围更广的互连网（internetwork/internet）。

名称 含义 协议要求
网络 把多台计算机及相关结点连起来 由所在网络决定
internet 多个网络互连而成的通用“互联网” 可采用任意协商的通信协议，不必是 TCP/IP
Internet 当今全球最大的开放、特定的因特网 使用 TCP/IP 协议族

易错：首字母小写的 internet 是普通名词；首字母大写的 Internet 指特定全球因特网。网络连接的是计算机/结点，互连网连接的是网络。

1.2 计算机网络的组成

1.2.1 按组成部分

组成 内容
硬件 端系统/主机、通信链路、交换设备（路由器、交换机等）、通信处理机（如网卡）
软件 资源共享软件和方便用户使用的工具软件
协议 网络的核心，规定数据传输应遵循的规则、格式和时序

1.2.2 按工作方式：边缘与核心

部分 构成 作用
边缘部分 所有直接供用户使用、接入互联网的主机（端系统） 用户通信（数据/音频/视频）和资源共享
核心部分 大量网络及连接它们的路由器 为边缘部分提供连通性与交换服务

1.2.3 按功能：通信子网与资源子网

子网 构成 作用
通信子网 传输介质、通信设备及相应协议 提供数据传输、交换、控制、存储能力，实现数据通信
资源子网 用于共享的设备及软件集合 向用户提供硬件、软件、数据资源共享服务

1.3 计算机网络的功能

  1. 数据通信：跨地域传输各类信息，并实现统一调配、控制和管理。
  2. 资源共享：共享硬件、软件、数据，互通有无、分工协作，提高利用率。
  3. 分布式处理：某机器负荷过重时，把复杂任务分给其他空闲节点，提高全系统利用率。
  4. 提高可靠性：多台计算机/资源可相互替代，单点故障不必导致服务完全中断。
  5. 负载均衡：把工作任务较均匀地分配给各网络节点。

1.4 三种数据交换方式

1.4.1 电路交换

通信前先在两端之间逐段建立一条专用通信通路，预留沿途链路带宽、交换设备端口或时隙等电路资源；它不一定是一根端到端独占的物理导线，但预留资源在传输期间由双方独占，结束后释放。流程是：建立连接 -> 数据传输 -> 释放连接，传统电话网是典型例子。

优点 缺点
专用路径建立后传输时延小、数据按发送顺序到达 建立连接耗时，对短促计算机通信不利
无链路争用/冲突，实时性强，可随时通信 路径即使空闲也被独占，线路利用率低
可传模拟或数字信号，交换控制相对简单 任一处故障通常须重新建立连接；灵活性差
中间交换结点不对完整报文做存储转发和逐报文检验，交换网自身不便进行逐跳差错恢复；端系统仍可另做端到端差错控制；不同速率终端难规格化互通

适合数据量很大且传送时间远大于建立呼叫时间的连续通信。

1.4.2 报文交换

报文是用户数据加上源/目的地址等控制信息形成的完整交换单位。报文交换采用存储转发：交换结点必须接收并完整存储整个报文，再查转发表决定下一跳；不同报文可独立选择路径。

优点 缺点
不需预先建立连接，可随时发送 必须完整收下报文才转发，端到端转发时延高
每段链路按需动态分配，利用率较高 不像分组交换那样统一把报文限制为较短的分组；长报文要求结点有足够缓存。实际报文仍受协议、设备缓存和链路等实现限制，并非无限长
路径故障可改选其他路径，可靠性较高 报文越长出错概率越大，出错时重传整个报文，代价大
在协议支持复制/多播时，可把报文送往多个目的地

1.4.3 分组交换

分组交换同样存储转发，但先把长报文划为受最大分组长度等约束的较小数据段；分组不必全部固定等长，分段时最后一段往往更短。每段加源地址、目的地址、编号等必要控制信息，构成分组（packet）。

长报文 -> 划分分组并加首部 -> 交换机缓存一个分组
      -> 读取目的地址、查转发表 -> 转发下一跳 -> 最终目的主机重组
优点 缺点
数据报方式没有连接建立阶段，适合突发式计算机数据；虚电路方式则需先建立 仍有逐跳存储转发、处理和排队时延
链路仅在分组经过时被占用，利用率高 每个小段都加首部，存在额外开销；开销比例取决于首部和有效载荷长度，并无通用的 5%–10% 定值
分组长度有上界且通常较小，缓存管理较容易 数据报服务下分组可能失序、丢失、重复，目的端须按编号处理
后一分组接收可同前一分组转发重叠，形成流水，加速整报文传输
分组较短时缓存需求和单次出错重传量较小，也有利于多个通信量交错共享链路 是否降低整个报文的出错概率还取决于误码模型、分组数量和差错控制方式，不能一概而论

1.4.4 三种方式的选择与辨析

对比点 电路交换 报文交换 分组交换
传输单位 连续比特流/专用通路 整个报文 分组
是否建立连接 是 否 数据报通常否；虚电路服务需先建立
资源占用 全程独占路径 逐段按需占用 逐段按需占用
交换节点 不需存完整数据 存完整报文后转发 存一个分组后即可转发
计算机突发数据适配性 较差 可用但时延/缓存大 最适合
  • 对突发业务，报文、分组交换通常比长期独占电路资源更能提高链路利用率。多跳发送较长报文时，分组可逐跳流水传送，通常比整报文存储转发更快；若报文很短、分组首部/处理开销明显或有拥塞，则不能无条件断言分组交换端到端时延更小。
  • 数据报服务通常没有建立阶段，分组独立选路且不保证按序到达；虚电路服务须先建立，网络保存虚电路状态，同一虚电路的分组沿预定路径逐跳转发。保存虚电路状态不自动等于可靠、无丢失，是否按序、检错或重传仍取决于具体协议和服务承诺。原 PDF 第 5 页的选择题答案是 D（数据报分组不一定按发送顺序到达）；该页解析把“虚电路的可靠通信由网络自身保证”写成通性，需按具体服务承诺判断。

INFO · 教材补充：数据报与虚电路不能只靠“是否分组”区分 二者都属于分组交换，差别在于网络层是否预先建立逻辑连接、沿途结点是否保存连接状态。

对比点 数据报服务 虚电路服务
建立阶段 无；每个分组可直接发送 有；先选定路径并建立虚电路，再传数据，最后释放
分组首部 通常携带完整目的地址 通常携带较短的虚电路标识，逐跳可被映射为本地标识
路径 每个分组独立查表，可能走不同路径 同一虚电路的分组通常沿既定路径转发
结点状态 网络核心不保存每条端到端连接状态 沿途交换结点保存虚电路表项
到达次序 可能失序 沿同一路径转发时通常保持次序
故障影响 后续分组可重新选路；已丢失分组仍需上层恢复 路径中结点/链路故障会破坏相关虚电路，通常需重建
服务质量 难以按连接预留资源 较便于按虚电路做资源预留、接纳控制和服务质量管理

虚电路是“逻辑连接”，不是电路交换那种端到端独占物理资源；数据报是“无连接”，也不等于完全没有路由表或控制平面状态。

1.5 计算机网络的分类

1.5.1 按覆盖范围

类型 英文 常见覆盖范围与特点
个人区域网 PAN/WPAN 个人工作空间内，以无线连接手机、平板等消费电子设备
局域网 LAN 数十至数千米，主机经高速线路相连；传统共享介质 LAN 多用广播技术，现代交换式以太网的单条链路通常为点到点
城域网 MAN 几个街区到整个城市，约 5–50 km；常采用以太网，常并入 LAN 讨论
广域网 WAN 数十至数千千米的长距离通信；是互联网核心，结点交换机间通常为高速大容量链路

传统教材概括：LAN 多采用广播技术，WAN 多采用交换技术。现代交换式以太网端口之间通常是全双工点到点链路，但交换机仍会在同一 VLAN/广播域内转发广播帧；无线、卫星网络也可使用广播式通信。

1.5.2 按传输技术：广播式与点对点网络

广播式网络中所有联网计算机共享一个公共通信信道。一台计算机发送分组时，其他联网计算机都能“听到”；各接收者再检查目的地址，只接收发给自己的分组。

  • 传统共享总线以太网和无线局域网使用广播式共享信道；现代交换式以太网的物理链路多为点到点，但 VLAN 内仍支持广播。
  • 无线、卫星通信网络也可采用广播式技术。
  • 点对点网络由一条条点到点链路连接节点；分组从源到目的通常需经过若干中间节点，并由路由选择决定路径。现代广域网骨干和交换式以太网端口链路常采用这种形态。

1.5.3 按拓扑结构

网络拓扑描述节点（主机、路由器等）与通信线路之间的几何关系，主要指通信子网拓扑。

拓扑 结构与优点 缺点/典型应用
总线形 一条公共传输线串接各主机；建网容易、增减节点方便、节省线路 重负载效率不高，任一总线故障敏感；常见于 LAN
星形 每终端以单独线路连中央设备；便于集中控制管理 成本高，中央设备是故障敏感点；常见于 LAN
环形 节点连成环，可单环或双环；令牌环是典型 课程模型中信号单向传输；常见于 LAN
网状 结点之间存在多条互连链路；教材所述有冗余路径的网状模型中，每个结点可经至少两条路径通向其他结点 冗余连接可提高可靠性，但控制复杂、线路成本高；常见于 WAN。部分网状网络不保证每对结点都有两条独立路径

1.5.4 其他常见分类维度

INFO · 教材补充

分类依据 类型 判断要点
使用者与运营属性 公用网、专用网 公用网由运营者向公众提供服务；专用网服务于某一组织内部需求
传输介质 有线网、无线网 有线使用双绞线、同轴电缆、光纤等；无线使用无线电、微波、红外等
交换方式 电路交换、报文交换、分组交换 判断交换单位、是否预留资源以及是否存储转发

这些分类维度可以交叉组合，例如“采用光纤点对点链路的公用广域分组交换网”；不要把某一维度的类别误当成互斥的全部标签。

1.6 网络性能指标

1.6.1 速率、带宽与吞吐量

指标 定义 单位/辨析
速率 节点在数字信道上传送数据的速率，又称数据率/比特率 bit/s、b/s、kb/s 等
带宽 在数字网络性能语境中，表示链路可达到的最高数据传输速率 此时以 bit/s 表示；模拟信道或频谱语境中的带宽仍指频率范围，常以 Hz 表示，须结合语境判断
吞吐量 单位时间内通过网络、信道或接口的实际数据量 对同一信道的统计口径，不超过该信道带宽；端到端吞吐量还受各段链路、协议、拥塞和设备等影响

1.6.2 时延

一个报文/分组从网络一端到另一端的总时延为：

$$d_{total}=d_{trans}+d_{prop}+d_{proc}+d_{queue}$$

分量 含义 公式/影响因素
发送时延（传输时延） 发送节点把分组所有比特推入链路的时间 $d_{trans}=L/R$，由分组长度 $L$ 和发送速率 $R$ 决定
传播时延 一个比特沿介质从链路一端到另一端的时间 $d_{prop}=D/v$，由距离 $D$ 和信号传播速率 $v$ 决定，与 $L,R$ 无关
处理时延 交换节点分析首部、提取数据、差错检验、查路由等时间 与设备/协议处理能力有关
排队时延 分组在输入/输出队列等待处理或转发的时间 与业务负载、队列/拥塞状态有关，变化最大

易错：发送时延不是信号在导线里“跑”的时间；传播时延不是“把所有比特发出去”的时间。前者看分组大小和链路速率，后者看距离和介质传播速度。

1.6.3 时延带宽积、RTT 和利用率

时延带宽积表示链路按速率 $R$ 持续发送、首比特即将到达终点时，链路“管道”中最多可容纳的在途比特数，亦称以 bit 为单位的链路长度；如果发送的数据不足这么多，实际在途比特数会更少：

$$\text{BDP}=d_{prop}\times R$$

其中 $R$ 是信道带宽。要让高速长距离链路持续不空转，未确认数据量/窗口量级通常需能覆盖 BDP。

往返时延（RTT）是发送端发出短分组后，收到接收端立即返回确认所经历的总时间。互联网中的 RTT 除双向传播外，还含中间节点的处理、排队、转发发送时延。

信道利用率表示有数据实际通过信道的时间占比：

$$U=\frac{\text{有数据通过时间}}{\text{有数据通过时间}+\text{无数据通过时间}}$$

1.6.4 有效吞吐量、丢包率、抖动与可用性

INFO · 教材补充

指标 含义 与相近概念的区别
有效吞吐量 goodput 单位时间交付给应用的有效载荷 不计协议首部、填充和重复传输，因此通常不大于吞吐量
丢包率 在规定观察范围内丢失分组数占应传分组数的比例 丢包可来自误码丢弃、缓存溢出、TTL 到期或策略过滤等，不能只归因于物理层误码
时延抖动 jitter 分组端到端时延随时间的变化程度 平均时延相同的两条路径，抖动可能不同；实时音视频常用缓冲吸收短时抖动
可用性 availability 系统在观察期间能够提供约定服务的时间比例 与单次传输是否正确不同，常同时受设备、链路、维护和恢复时间影响

若在一段时间内发送 $N_s$ 个分组、目的端成功收到 $N_r$ 个，且统计口径一致，则经验丢包率可写为：

$$P_{loss}=\frac{N_s-N_r}{N_s}$$

可靠性、可用性、时延、抖动与吞吐往往需要联合评价。例如通过重传可降低应用可见的数据丢失，却会增加时延、抖动和额外流量；不能只看单一指标断言网络整体性能更好。

1.7 同步与异步传输

方式 特点
同步通信 双方先建立同步并持续调整至相同频率，连续发送/接收同步比特流
异步通信 字符间间隔可以任意；发送端可随时发送，接收端需随时准备，故每字符开始和结束处须带标识符

异步传输的边界标识常体现为起始位、停止位等帧定界信息；它不代表整个网络完全没有时钟，而是收发双方不要求维持连续、严格同步的字符流。

题型：#时延与交换方式判断

第一部分：解题方法

  1. 看“独占通路、先建立”判断电路交换；看“整报文收全再转发”判断报文交换；看“切分小分组、逐分组存储转发”判断分组交换。
  2. 时延题先分别列 $L/R$ 与 $D/v$，再按路径上的每跳处理/排队情况相加，避免混淆单位。
  3. 问“最高能力”选带宽，问“实际通过量”选吞吐量，问“数据正在传的比例”选利用率。
  4. 问应用真正拿到多少有效数据时看 goodput；协议开销和重传流量不能算入有效载荷。

第二部分：易错点

  • 分组交换可有虚电路或数据报服务；“分组交换一定无连接”不严谨。
  • 时延带宽积中的时延是传播时延，单位乘带宽后是 bit，不是秒或 B/s。
  • 长距离但很短的分组可能传播时延主导；大分组而短链路可能发送时延主导。

1.8 本节复盘

  • 网络连接节点和链路；互联网连接多个网络。internet 是泛称，Internet 是使用 TCP/IP 的特定全球网络。
  • 网络可按硬件/软件/协议、边缘/核心、通信/资源子网划分；核心提供交换连通，边缘承载用户通信和共享。
  • 电路交换预留并独占沿途电路资源；报文交换整报文存储转发；分组交换以小分组流水式存储转发，适合突发数据。
  • LAN、MAN、WAN、PAN 按范围划分；“LAN 多广播、WAN 多交换”是传统教材概括，现代交换式以太网链路通常为点到点。
  • 发送时延为 $L/R$，传播时延为 $D/v$，总时延还包括处理与排队；BDP 为 $d_{prop}R$，带宽是最高而吞吐量是实际。
  • 有效吞吐量只统计应用载荷；丢包率、时延抖动和可用性与吞吐量共同描述服务质量，不能互相替代。
