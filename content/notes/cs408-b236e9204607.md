## 0.1 写作目标
+ 408 的 PDF 正文统一通过 MarkItDown 0.1.6 提取；公式、波形、结构图、表格和纯图片页还要结合 PDF 页面渲染核验。提取内容不做简单摘要，而是改写成和“数学英语笔记”一致的 Obsidian 学习笔记。
+ 每篇笔记都要做到：
	+ 1. 不遗漏 PDF 中的知识点、例子、面试题、题型；
	+ 2. 删除水印、页码、广告和无意义残留；
	+ 3. 公式统一写成 LaTeX；
	+ 4. 原 PDF 中没有展开但学习需要的地方，可以补充解释、例题或易错点；
	+ 5. 对 MarkItDown 已提取的图表文字、PDF 页面中的必要图示、库内独立知识图和已有合法附件，优先改写为可检索的结构化文字、表格、流程图或公式；不能准确数字化且确有知识价值的图，保留清晰图片并补充文字说明；
	+ 6. 原来源内容与扩展内容分开记录。正式来源笔记保留 `source`；不属于原 PDF/知识图的新增主题必须使用 `supplement: true` 和 `basis` 明确标注“教材补充”。

## 0.2 笔记结构
**基本结构**
+ YAML 属性区：
	+ `title`
	+ `tags`
	+ `categories`
	+ `date`
	+ `source`
+ 正文：
	+ `## x.1 一级知识点`
	+ `### x.1.1 二级知识点`
	+ `**概念**`
	+ `##### **定义**：#关键词`
	+ `> 描述：`
	+ `**解释**`
	+ `### 题型：#题型名`
	+ `#### 第一部分：解题方法`
	+ `#### 第二部分：典型例题`
	+ `#### 第三部分：知识点复盘`

## 0.3 语言风格
+ 用自己的话重写，不逐句照搬 PDF。
+ 保留所有细节，但重新组织层级。
+ 用 `+` 做列表，子项用 Tab 缩进。
+ 重点内容用 `**加粗**`。
+ 推导关系用 `` `->` ``。
+ 对比类知识点优先用表格。
+ 结尾必须有“本节复盘”。

## 0.4 公式规范
+ 所有公式用 LaTeX。
+ 行内公式使用 `$...$`。
+ 多行推导使用：
```latex
$$
\begin{aligned}
...
\end{aligned}
$$
```
+ 复杂度写作：$O(1)$、$O(n)$、$O(n^2)$、$O(n\log n)$。
+ 不把普通中文等式强行写进 LaTeX，除非它确实是公式。

## 0.5 图片和图表
+ PDF 正文以 MarkItDown 0.1.6 提取结果为主；同时检查新鲜渲染页面，核对提取工具容易遗漏或打乱的公式、波形、结构关系、数值表格和纯图片内容。
+ PDF 页面中的图示按以下顺序处理：
	+ 能准确数字化时，改写成 Markdown 表格、Mermaid、LaTeX 或文字流程；
	+ 不能准确数字化且图本身承担知识表达时，裁取清晰区域作为库内附件，并写明图意、符号、条件和来源页；
	+ 装饰、水印、重复内容和仅用于排版的图片不入库。
+ 对库内独立存在的 PNG/JPG/SVG 知识图或已有附件：
	+ 结构关系优先改写成可检索的 Markdown 表格、Mermaid 或文字流程；
	+ 原图确有保留价值时，用 `![[图片名.png]]` 引用，并补充文字说明；
	+ 装饰图或与正文完全重复的图片可以不重复嵌入。
+ 不保留无明确处置计划的“待补图”占位；无法由当前材料确认的内容必须明确标注证据边界，不能把“已提取正文”写成“已逐页核验”。

## 0.6 处理顺序
+ 先按科目顺序处理：
	+ 1. 数据结构；
	+ 2. 操作系统；
	+ 3. 计算机组成原理；
	+ 4. 计算机网络；
	+ 5. 复试常考科目。
+ 每次只精写少量文件，确认质量后再继续。
