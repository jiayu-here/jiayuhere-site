Privacy

How Jiayu Lab uses visit analytics, browser-based tools, external links and public contact information.

Visit analytics

This site uses Google Analytics to understand page visits, commonly used pages and device categories so that maintenance can focus on useful content. Google may set identifiers required for analytics. Jiayu Lab does not use these statistics to actively collect names, phone numbers, site passwords or account credentials.

Toolbox input

The base converter, serial and circuit calculators, Markdown preview, formula reference and LaTeX tester run in the current browser. These tools have no server-side submission endpoint configured, so form input is not sent to a Jiayu Lab server.

Public contact information

The contact, resume and GitHub pages show only contact routes that the site owner has chosen to make public. Do not submit secrets, tokens, identity documents, private project material or other sensitive information through public pages.

External links

The site links to third-party services such as GitHub, learning resources and social platforms. After opening an external page, that service's own privacy and security policies apply.

Contact

If you find information that should not be public, or want to ask about public contact information associated with this site, use the public contact route and identify the specific page.
