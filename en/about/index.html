About

Building verifiable systems across communications, hardware and software.

I focus on communications and DSP, FPGA and embedded systems, and the software tools that support verification and delivery. This site records how a problem is defined, implemented, tested and documented—not only the final result.

Focus

Three paths I am connecting

These are not isolated labels. Together they form a complete path from signals and algorithms to hardware behavior and a reproducible handoff.

01

Communications and DSP

Move modulation, sampling, spectra, BER and fixed-point error from equations into reference models and observable data.

  • Sampling and spectra
  • Fixed-point design
02

FPGA and Embedded

Use RTL, testbenches, timing constraints and board interfaces to build hardware that can be evaluated, debugged and integrated.

  • Verilog
  • STM32 / FreeRTOS
  • Board interfaces

Software and Delivery

Use scripts, databases, containers and technical documentation for reference checks, visualization, reproducibility and publication.

  • Python / MATLAB
  • Databases / Docker
  • Tests and docs
