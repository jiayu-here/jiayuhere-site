408 主课

  • 数据结构导航：逻辑结构、存储结构、算法与代码实现。
  • 操作系统导航：进程、内存、文件与 I/O 管理。
  • 计算机组成原理导航：数据表示、存储器、指令、CPU、总线与 I/O。
  • 计算机网络导航：从体系结构、物理层到应用层。

复试扩展

  • 复试常考科目导航：机器学习、深度学习、数据库与软件工程。

跨科目桥梁

存储体系：硬件机制到操作系统抽象

存储器层次结构 → Cache → 页表、TLB 与虚拟存储器硬件 → 内存管理基础 → 虚拟内存管理策略

I/O 链路：中断、接口与设备管理

中断 → I/O 接口 → I/O 方式 → 操作系统 I/O 管理

图算法到网络路由

最短路径与图的经典应用 → 路由协议

机器学习到深度学习

神经网络模型 → 神经网络与后向传播 → 卷积神经网络

需求、数据与软件设计

软件需求工程 → 数据库设计 → 软件设计与实现
