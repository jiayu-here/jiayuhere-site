Lecture 4: Reading Past Papers — 2007

Graduate Entrance Examination English study notes: Lecture 4: Reading Past Papers — 2007. Original examples, diagrams, and exercises are retained.

Key Points

Concept: When translating subject clauses, you can first translate them in order, then adjust the order according to the logic of the sentence;

  • For example: it is not obvious how the capacity to visualize object and to figure out numerical patterns suits one to ... '

Concept: appositive structure

  • I love beijing,a beauty city.
  • When translating, it can be translated the same as in a relative clause: this kind or this situation;

Concept: Independent subjectivity

Reading Summary

  • If the question is an example and the option contains words like topic that represent the topic, prioritize them;
  • When more... than... sentences appear in the text, more is followed by a positive relationship, than is followed by a negative relationship;
  • Pay attention to reading the question, and be aware that pronouns are likely to appear in the -> option to substitute concepts;
  • whatever means: anything that...
  • whatever happens: means "whatever happens";
  • now: turning point, followed by the main point;
  • rather than: contrast, with 'than' followed by the content being denied;
  • The author's viewpoints in postgraduate exam articles are usually unique and rarely noticed;
  • Quoting a proverb at the beginning aims to clarify the main point of the article;
  • Function of the colon: explains what came before, so it can represent the previous content;
  • surely: indicates that reality and what should be done are different, connecting what needs to be done at the end of the text;
  • few... more...: Can represent the superlative level;
  • In the text, it appears: negation + comparative , which can be directly translated as superlative form;
