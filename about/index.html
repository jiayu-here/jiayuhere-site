关于我

把通信、硬件与软件，连成可验证的系统。

我关注通信与数字信号处理、FPGA 与嵌入式，以及支撑验证和交付的软件工具。这个网站记录问题如何被定义、实现、验证和整理，而不只展示最后的结果。

我的工作方式

从问题到交付

  1. 01定义输入、输出与验收
  2. 02实现拆分算法与接口
  3. 03验证仿真、编译与测试
  4. 04交付文档、限制与复现

方向

我正在连接的三条主线

方向并非彼此分开的标签；它们共同服务于从信号与算法到硬件行为，再到可复现交付的完整链路。

01

  • 采样与频谱
  • 定点实现
02

FPGA 与嵌入式

  • 板级接口
03

软件与交付

让脚本、数据库、容器和技术文档承担参考验证、数据展示、环境复现与成果发布。

  • Python / MATLAB
  • 数据库 / Docker
  • 测试与文档
